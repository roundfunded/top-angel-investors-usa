# Top angel investors in the USA

Who this is for: founders searching top angel investors USA who need a useful list definition. How this was compiled: ranking criteria, not a scraped name dump. Fundraising is super easy when the angel writes your stage. Live filter: [top angel investors USA](https://roundfunded.com/en/tools/top-angel-investors-usa).

Last updated: 2026-08-14

## Problem

A celebrity name with no recent check is not "top" for your raise. A USA angel who only does biotech is not top for fintech.

## Criteria for a useful US angel list

| Criterion | What to check |
| --- | --- |
| Stage | Their last few rounds vs your round |
| Check size | Public range if they state one |
| Geo | Where they live and where they write in the USA |
| Thesis | Sectors they repeat |
| Recency | Checks in the last 12 to 24 months |

This repo does not publish a named top-50 with emails or phones.

## How to use this

1. Lock stage, thesis, and check size.
2. Drop anyone with no recent startup checks.
3. Use [top angel investors USA](https://roundfunded.com/en/tools/top-angel-investors-usa) for this filter on the Round Funded database (60,000+ investors overall).
